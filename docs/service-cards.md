# 服务应用图标

服务页采用手机桌面式网格：只展示圆角图标、最多两行的名称和必要状态角标，不再展示卡片底板、地址和底部按钮。手机图标 64px、桌面 72px；列宽随字号扩展，普通手机约四列、320px 窄屏约三列，桌面自适应多列。

## 使用场景

- 找应用：搜索或筛选后，点击图标或单元空白处访问网页服务（新标签页）；点击名称打开应用详情浮层，保留列表筛选与滚动位置。TCP/UDP 图标直接复制地址，显示成功反馈；失败时当前项展开整行，保留再次复制和手动复制能力。
- 服务不可用：已关闭或无公网地址的图标置灰，不执行访问或复制，名称仍可进入详情。正常状态不常驻显示，异常、部分可用、等待、关闭和未知状态以不同符号角标提示，并保留读屏文字；完整状态和错误在详情查看。
- 管理多个服务：点击“选择”或在手机长按图标、名称、单元空白处进入多选；抬手不触发访问或复制。选择模式下点击图标、名称、空白仅切换选择，左上角圆形复选框有 44px 点击区域，选中描边只作用于图标。滚动、滑动和多指取消长按。
- 设置图标：点击表单名称旁的图标展开搜索面板，选择只修改草稿；关闭表单沿用未保存确认。
- 网络不可用：图标加载失败回退网页／端口通用图标，不影响打开、复制和详情操作。

## 图标数据

`web/src/data/hd-icons.json` 保存 HD-Icons 的完整相对路径目录，初次导入为 1815 项：圆角 1085、圆形 126、SVG 604。来源为 https://raw.githubusercontent.com/xushier/HD-Icons/main/icons.json 。同一应用的不同图标分别计数。

目录在选图时动态加载，默认圆角风格，每页 24 项；图片通过 jsDelivr 按需加载，不打包、不代理，也不在运行时同步目录。更新目录时，从上游 `icons` 数组提取 `url` 中 `https://raw.githubusercontent.com/xushier/HD-Icons/main/` 后的路径，保留全部样式及文件名。Web 和 Server 使用同一份目录。

服务接口新增可空 `icon_id`：创建省略时为默认图标；更新省略时保留原图标，显式 `null` 恢复默认。只接受目录中的相对路径，非法值返回 400 并回滚本次服务写入。字段不下发给 Agent。现有数据库增量添加可空列，旧客户端和批量换设备无需传入图标字段。

许可及来源见 `web/public/licenses/HD-Icons.txt` 和 `THIRD_PARTY_NOTICES.md`。上游请求项目批量使用时告知作者；本次开发未代发消息。

## 应用详情浮层

详情以居中圆角浮层展示，手机四周至少留白 16px、桌面最宽 760px，高度不超过可见视口的 85%。应用摘要固定在顶部，正文按异常、访问地址、服务配置、连接状态与管理操作分组并独立滚动。

普通点击名称不改变网址或创建桌面标签；保留详情链接以支持修饰键和旧网址直达。关闭恢复名称焦点，应用被删除时回到搜索。编辑暂时收起详情，完成后恢复详情内部位置；删除仍需确认。详情内 Agent 和域名链接关闭浮层后导航。

图标通过无回弹弹簧从列表位置展开到摘要；关闭可打断打开动画。没有可见来源、窗口尺寸变化时退化为淡出，减少动态效果时仅淡入淡出。详情显示时继续刷新状态，编辑和确认期间暂停自动刷新。
