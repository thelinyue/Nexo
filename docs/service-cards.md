# 服务视图与应用图标

## 列表与公网入口（编码前场景说明）

服务页默认列表，在搜索筛选工具栏切换「列表／图标」，本浏览器记住选择。切换保留搜索、筛选和多选，图标访问网页或复制端口地址，名称打开详情，长按及选择模式沿用现有操作。

桌面按「服务／公网入口／模式／状态」四列对齐，模式分两行显示「内网穿透／反向代理」和「单节点／DNS 分流／回源延迟优先／主备切换」。手机首行显示 48px 图标、名称和文字状态，下面直接展示入口及两类模式；多个入口和长节点名称允许换行，无横向滚动。

场景：服务策略已从香港选择日本，但 DNS 写入尚未完成。列表仍显示最近记录的香港入口，标注「待同步」，并提示目标日本节点。DNS 更新一部分后失败时，展示已记录的入口并标注「同步失败」，不能把所有健康候选当成整组已同步。DNS 分流直接列出所有已记录入口。关闭服务显示配置节点和「已关闭」。

服务响应新增可空只读 `node_entry`：`entries` 每项包含 `ipv4`、可空 `node_id` 和 `node_name`，`sync_status` 为 `synced`、`pending`、`failed`、`disabled` 或 `unmanaged`，`synced_at` 为最近完整同步时间或 `null`。只读取当前工作空间、服务、域名和主机名的既有 DNS 记录，兼顾多节点及 IPv6 直连的 IPv4 写入记录；不新增 DNS 请求、数据库字段或转发行为。

IPv6 直连协调器没有独立保存完整 DNS 同步时间，相关入口返回 `synced_at: null`；直连地址变更但发布地址尚未更新时标注待同步，不用心跳时间代替 DNS 同步时间。

只有记录地址能唯一对应当前配置中的未删除节点时显示名称；地址变更、节点移除或匹配不唯一时显示 IPv4。同步状态结合当前节点、策略、健康和已有同步结果判断，不能只比较版本号。名称、图标等展示字段变化不使入口变为待同步。

反向代理和未托管 DNS 的服务直接展示配置节点及现有状态。旧 Server 缺少 `node_entry` 时标注「入口状态未提供」，避免推断已同步。开启 IPv6 直连时直接显示标识，并将公网节点入口标明为 IPv4；刷新失败保留既有「保留上次数据」提示。记录表示 Nexo 最近确认的 DNS 入口，客户端的实际连接仍可能受缓存与已有连接影响。

## 图标视图

图标视图采用手机桌面式网格：只展示圆角图标、最多两行的名称和必要状态角标，不再展示卡片底板、地址和底部按钮。手机图标 64px、桌面 72px；列宽随字号扩展，普通手机约四列、320px 窄屏约三列，桌面自适应多列。

## 使用场景

- 找应用：搜索或筛选后，点击图标或单元空白处访问网页服务（新标签页）；点击名称打开应用详情浮层，保留列表筛选与滚动位置。TCP/UDP 图标直接复制地址，显示成功反馈；失败时当前项展开整行，保留再次复制和手动复制能力。
- 服务不可用：已关闭或无公网地址的图标置灰，不执行访问或复制，名称仍可进入详情。正常状态不常驻显示，异常、部分可用、等待、关闭和未知状态以不同符号角标提示，并保留读屏文字；完整状态和错误在详情查看。
- 管理多个服务：点击“选择”或在手机长按图标、名称、单元空白处进入多选；抬手不触发访问或复制。选择模式下点击图标、名称、空白仅切换选择，左上角圆形复选框有 44px 点击区域，选中描边只作用于图标。滚动、滑动和多指取消长按。
- 设置图标：点击表单名称旁的图标展开搜索面板，选择只修改草稿；关闭表单沿用未保存确认。
- 网络不可用：图标加载失败回退统一的暖橙应用方块图标，不影响打开、复制和详情操作。

## 图标数据

默认图标采用暖橙底色 `#E89456` 和四枚奶油白 `#FFF6E9` 圆角方块，所有协议统一使用。SVG 使用 64×64 坐标，方块大小 14、间隔 4、圆角 3，整体居中；沿用容器圆角并随 48px 列表／表单、56px 详情、64px 手机图标视图和 72px 桌面图标视图等比缩放，明暗主题使用同一配色。

场景：服务未设置图标、在选择器恢复默认或自定义图片加载失败时，列表、详情和表单均显示本地内联 SVG，无需请求图标服务。正常的自定义图片和上传预览沿用原有显示；默认图标只作装饰，状态角标和按钮的可访问名称仍由现有界面提供。

`web/src/data/hd-icons.json` 保存 HD-Icons 的完整相对路径目录，初次导入为 1815 项：圆角 1085、圆形 126、SVG 604。来源为 https://raw.githubusercontent.com/xushier/HD-Icons/main/icons.json 。同一应用的不同图标分别计数。

目录在选图时动态加载，默认圆角风格，每页 24 项；图片通过 jsDelivr 按需加载，不打包、不代理，也不在运行时同步目录。更新目录时，从上游 `icons` 数组提取 `url` 中 `https://raw.githubusercontent.com/xushier/HD-Icons/main/` 后的路径，保留全部样式及文件名。Web 和 Server 使用同一份目录。

服务接口新增可空 `icon_id`：创建省略时为默认图标；更新省略时保留原图标，显式 `null` 恢复默认。只接受目录中的相对路径，非法值返回 400 并回滚本次服务写入。字段不下发给 Agent。现有数据库增量添加可空列，旧客户端和批量换设备无需传入图标字段。

许可及来源见 `web/public/licenses/HD-Icons.txt` 和 `THIRD_PARTY_NOTICES.md`。上游请求项目批量使用时告知作者；本次开发未代发消息。

## 应用详情浮层

详情以居中圆角浮层展示，手机四周至少留白 16px、桌面最宽 760px，高度不超过可见视口的 85%。应用摘要固定在顶部，正文按异常、访问地址、服务配置、连接状态与管理操作分组并独立滚动。

普通点击名称不改变网址或创建桌面标签；保留详情链接以支持修饰键和旧网址直达。关闭恢复名称焦点，应用被删除时回到搜索。编辑暂时收起详情，完成后恢复详情内部位置；删除仍需确认。详情内 Agent 和域名链接关闭浮层后导航。

图标通过无回弹弹簧从列表位置展开到摘要；关闭可打断打开动画。没有可见来源、窗口尺寸变化时退化为淡出，减少动态效果时仅淡入淡出。详情显示时继续刷新状态，编辑和确认期间暂停自动刷新。
