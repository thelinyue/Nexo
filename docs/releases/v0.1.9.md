# Nexo v0.1.9

Nexo `v0.1.9` 修复 `v0.1.8` 中 Caddy 2.11 无法加载公网 HTTPS 配置的问题。

## 修复

- 按 Caddy 2.11 原生 JSON 类型将 `trusted_proxies_strict` 写为整数开关。
- 保留仅信任 `127.0.0.1/32` 和 `::1/128` 回环代理的安全边界。
- 恢复已有根证书选择、泛域名证书自动申请，以及精确 Web Service Host 路由。

## 升级与回滚

正式部署使用 `ghcr.io/thelinyue/nexo-server:0.1.9`。从 `v0.1.8` 升级不新增数据库迁移；VPS 只需升级 Server，Agent 无需变更。
