# Nexo v0.2.3

本次仅发布 Server。Agent 没有代码变化，继续使用 `0.2.0` 镜像。

## 变化

- 新生成的 Docker Compose 配置按入网记录使用独立的数据目录。
- 新生成的 `docker run` 命令按入网记录使用独立的 Docker 数据卷，避免删掉旧容器后误用旧 Agent 身份。
- 保留 v0.2.2 的直显 Compose 配置文件和单条 `docker run` 命令。

## 升级与发布组件

本次仅发布 Server：

- `ghcr.io/thelinyue/nexo-server:0.2.3`

Agent 保持：

- `ghcr.io/thelinyue/nexo-agent:0.2.0`

本版本没有数据库迁移。升级前备份现有 Server 数据和 Compose 配置。在现有部署配置中，只将使用 Server 镜像的服务改为 `ghcr.io/thelinyue/nexo-server:0.2.3`，拉取并重建这些服务。不要拉取或重建 Agent。
