# Nexo v0.2.15

## 发布组件

- Server（含 Web 与 x86_64、ARM64 原生节点安装包）：`ghcr.io/thelinyue/nexo-server:0.2.15`。
- Agent 本次无代码变化，不发布 `0.2.15` 镜像；已升级的 Agent 保持 `ghcr.io/thelinyue/nexo-agent:0.2.14`，未升级的 Agent 按 [v0.2.14](https://github.com/thelinyue/Nexo/releases/tag/v0.2.14) 单独更新。
- 部署包仅包含 Server 的 Compose、TOML、发布清单和许可证，不替换 Agent 的 Compose、数据目录和身份。

## 修复

- 服务表单的协议列加宽，在 Linux 字体及 320px 窄屏下完整显示 `TCP+UDP`，地址和端口仍在同一行且可编辑。用户列表测试等待响应式布局稳定后再测量几何位置。
- `v0.2.14` 的 Server 浏览器 CI 因上述协议标签裁切失败；本版本补齐修复与跨平台验收。普通 Tunnel 数据连接的 TCP_NODELAY 改进继续保留，性能数据与限制见 [测量记录](https://github.com/thelinyue/Nexo/blob/v0.2.15/docs/performance-nodelay-2026-09-30.md)。
- 本次无数据库迁移，保留原 Server 数据、配置和节点身份。

## 更新

核对 GitHub Release 的两种原生节点包、仅含 Server 的 Docker 部署包与 `SHA256SUMS` 后，停止 Server 并备份完整数据目录、Compose 与自定义配置。保持原挂载、网络和环境变量，将 Server 镜像固定为 `0.2.15`，只重建 Server：

```bash
docker compose pull nexo-server
docker compose up -d --no-deps nexo-server
curl --fail --max-time 5 http://127.0.0.1:8280/health
```

确认原账号、Agent 在线及既有服务可访问。Agent `0.2.14` 可与 Server `0.2.15` 配合使用；回退 Server 时恢复升级前镜像标签和完整数据、配置备份。
