# Nexo v0.1.14

Nexo `v0.1.14` 修复移动端官方 Tailscale OIDC 回跳、访问控制策略预览、设备地址展示和 Agent tailscaled 状态目录。

## 新增与修复

- PWA 只在 OIDC 登录 ticket 页面自动接管旧 Service Worker，普通页面仍由用户确认更新；`/oidc/*` 不再被 SPA fallback 截获。
- 访问控制页面通过 GET 校验当前已保存策略，编辑中的候选规则仍通过 POST 校验，不再生成 `preview` 虚构目标。
- 设备列表对 IPv4、IPv6 和兼容组网地址去重，保留真实双栈地址。
- Agent 启动 tailscaled 时设置持久化 `--statedir`，沿用原有 `tailscaled.state`，消除 Tailnet Lock 状态目录告警。
- OIDC JWKS 输出标准 `use` 字段。

## 升级与回滚

正式部署使用 `ghcr.io/thelinyue/nexo-server:0.1.14` 和 `ghcr.io/thelinyue/nexo-agent:0.1.14`。升级前请备份完整数据目录；本版本不新增数据库迁移。Agent 升级时保持原有 `data/nexo-agent` 持久卷，确认设备身份和 Tailscale Node 不变。回滚时恢复对应旧镜像和数据备份。
