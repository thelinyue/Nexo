# Nexo v0.2.0

Nexo v0.2.0 将产品收敛为 TCP、HTTP、HTTPS 内网穿透服务，移除 Headscale、Tailscale 及虚拟组网管理。本版本同时修改 Server 和 Agent，两端都需要升级。

## 主要变化

- 提供多工作空间账号、登录会话、密码恢复和设备入网审批。
- Agent 使用 mTLS 控制与数据通道，支持设备身份自动续签和管理员批准的身份恢复。
- 管理页面统一配置 TCP、HTTP、HTTPS 服务、公网域名、Cloudflare DNS 和证书状态。
- 移除 Headscale/Tailscale 控制面、Mesh 管理功能及其数据库结构。

## 全新安装与数据兼容

本版本只支持全新安装，不支持从 v0.1.x 原位升级。Server 检测到旧版数据结构后会拒绝启动；它不会转换、覆盖或删除旧数据目录。

升级前备份整个 Nexo 数据目录，并保留旧版 Compose 配置和环境变量以便回退。启动 v0.2.0 时配置一个空的数据目录；不要将 v0.1.x 的数据目录直接挂载给新 Server。旧账号、设备、隧道、域名及组网配置不会迁移，需要重新配置；Agent 需要向新 Server 重新注册。旧目录会保留，可在回退到 v0.1.x 时恢复。

新增域名需要重新验证并配置 Cloudflare 凭据。公网证书和 DNS 记录应按新安装逐项核对，避免在切换期间重复申请证书或误改 DNS。

## 发布组件

本次发布 Server 和 Agent：

- `ghcr.io/thelinyue/nexo-server:0.2.0`
- `ghcr.io/thelinyue/nexo-agent:0.2.0`

部署时同时更新 `nexo-server` 和所有 `nexo-agent`，并使用新的空 Server 数据目录。不要复用旧 Agent 身份目录；完成入网审批后再恢复服务配置。

## Docker Compose 一键部署

以下命令适用于已安装 Docker Engine、Docker Compose v2 和 `curl` 的 Linux/amd64 主机。Server 使用全新的数据目录；不要将 v0.1.x 数据复制或挂载到该目录。先在 Server 主机复制执行：

```bash
mkdir -p "$HOME/nexo-v0.2.0/data/nexo" && cd "$HOME/nexo-v0.2.0" && curl -fL https://raw.githubusercontent.com/thelinyue/Nexo/v0.2.0/compose.yml -o compose.yml && docker compose -f compose.yml pull && docker compose -f compose.yml up -d
```

在每台 Agent 主机复制执行以下命令。运行时输入 Server 的 Web/API 地址和管理页面生成的一次性入网 Token；Token 会写入权限受限的 `.env` 文件：

```bash
bash <<'NEXO_DEPLOY'
set -euo pipefail
install_dir="$HOME/nexo-agent-v0.2.0"
mkdir -p "$install_dir/data/nexo-agent"
cd "$install_dir"
curl -fL https://raw.githubusercontent.com/thelinyue/Nexo/v0.2.0/compose.agent.yml -o compose.agent.yml
if [ ! -f .env ]; then
  read -r -p 'NEXO_SERVER_URL: ' server_url </dev/tty
  read -r -s -p 'NEXO_ENROLLMENT_TOKEN: ' enrollment_token </dev/tty
  printf '\n'
  if [ -z "$server_url" ] || [ -z "$enrollment_token" ]; then
    echo 'Server 地址和入网 Token 不能为空' >&2
    exit 1
  fi
  umask 077
  printf 'TZ=Asia/Shanghai\nNEXO_SERVER_URL=%s\nNEXO_ENROLLMENT_TOKEN=%s\n' "$server_url" "$enrollment_token" > .env
  unset enrollment_token
fi
docker compose -f compose.agent.yml pull
docker compose -f compose.agent.yml up -d
NEXO_DEPLOY
```
