# Nexo v0.1.16

Nexo `v0.1.16` 是 Server-only 正式版本，改进官方 Tailscale 客户端命名和 SiteLink 静态路由确认。Agent 没有代码变化，继续使用 `0.1.14`，无需升级。

## 修复与改进

- 官方 Tailscale 客户端上报 `localhost` 时要求先填写可识别的设备名称，避免占位名称进入设备列表。
- 认领官方客户端时同步有效主机名到 Headscale，并在后续同步中保留有效名称。
- SiteLink 路由引导增加组网客户端回程路由，只有本站所有必要下一跳可用时才能完成路由确认。
- 新增数据库迁移，清理旧的站点级路由确认状态，使新增路由重新经过确认。

## 镜像与升级

本次仅发布：

- `ghcr.io/thelinyue/nexo-server:0.1.16`

Agent 保持：

- `ghcr.io/thelinyue/nexo-agent:0.1.14`

升级前备份 `./data/nexo`，只拉取并重建 `nexo-server`。不要为本版本创建或部署 Agent `0.1.16`。数据库迁移会在 Server 启动时事务执行；回滚前请确认数据库备份可用。
