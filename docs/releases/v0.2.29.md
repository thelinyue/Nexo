# Nexo v0.2.29

## 更新内容

- 修复公网慢链路上，Hermes 等应用并行下载大脚本时触发 HTTP/3 写超时并重置请求的问题。穿透入口为源站明确允许公开缓存的 JavaScript 和 CSS 完整响应协商 Zstandard 或 gzip。
- 每个穿透服务的脚本和样式 GET、HEAD 请求共用最多 32 条回源连接，回源在响应头前发生传输错误时最多重试两次。

## 发布与升级

本次发布 Server 镜像 `ghcr.io/thelinyue/nexo-server:0.2.29`，以及 Linux x86_64、ARM64 独立 VPS 节点包。现有 Agent 0.2.27 可配合新版入口使用。

升级前备份 Compose、数据库、配置、证书和节点身份。将 Server 镜像固定到 `0.2.29`，沿用现有挂载、网络与环境变量。

```sh
docker compose pull nexo-server
docker compose up -d --no-deps nexo-server
docker compose exec -T nexo-server nexo --version
curl --fail --max-time 5 http://127.0.0.1:8280/health
```

Server 上线后可从管理界面逐个更新独立节点。检查设备重新连接，并从实际公网入口验证静态资源和 WebSocket。需要回退时，恢复升级前的组件版本、配置和配套数据备份。
