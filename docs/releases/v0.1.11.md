# Nexo v0.1.11

Nexo `v0.1.11` 增加公网域名运行诊断和手动证书生命周期管理。

## 新增与修复

- 公网域名页面增加运行日志弹窗，支持按域名、级别、类别和关键词筛选，并可导出脱敏日志。
- 手动证书上传校验成功后原子启用；删除证书后继续保持手动模式，不会悄悄恢复自动申请。
- 修复 Caddy 手动证书加载和 SNI 证书选择策略，避免不存在的证书文件被提交给 Caddy。
- 新增数据库迁移 `0019_public_domain_runtime_events.sql`，仅保存面向管理员的脱敏运行事件。

## 升级与回滚

正式部署使用 `ghcr.io/thelinyue/nexo-server:0.1.11` 和 `ghcr.io/thelinyue/nexo-agent:0.1.11`。升级时 Server 会自动创建运行日志表，Agent 无需额外配置。
