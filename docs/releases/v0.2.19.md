# Nexo v0.2.19

## 发布组件

- Server（含 Web 与 x86_64、ARM64 原生节点安装包）：`ghcr.io/thelinyue/nexo-server:0.2.19`。
- 本次仅 Server 有实际代码变化。Agent 不发布新镜像或部署包，现有 `0.2.18` 镜像和节点身份保持不变。

## 更新内容

- 网页与 PWA 发现新版时提示用户刷新，不自动打断操作；表单打开、写请求进行中及设置草稿均保留原有保护。其他标签页激活新版也不会自动刷新当前页面；普通 HTTP 入口同样支持更新探测。
- Server 为页面入口、Service Worker 和清单添加缓存重新验证响应头，避免继续使用旧入口。
- 服务表单粘贴 HTTP/HTTPS 网址时自动填入协议、地址和端口，支持 IPv6 和默认端口；路径、查询参数和片段不会保存，并明确提示。带凭据或无效网址不自动拆分。
- 账号菜单和移动端更多菜单按内容确定宽度，保持视口约束和键盘操作。

## 更新方式

从 Server `0.2.18` 更新可保留账号、服务、配置与设备身份，无新增数据库结构迁移。核对发布包和 `SHA256SUMS`，停止 Server 并备份完整数据目录、Compose 和自定义配置。保留原挂载、网络与环境变量，将 Server 镜像标签固定为 `0.2.19` 后只重建 Server：

```bash
docker compose pull nexo-server
docker compose up -d --no-deps nexo-server
curl --fail --max-time 5 http://127.0.0.1:8280/health
```

Compose 不在当前目录时使用 `-f <文件路径>`。确认 Server 健康、Agent 重新连接、原设备身份与服务绑定保留，检查既有服务访问。Agent 无需拉取或重建。需要回退时停止 Server，恢复原镜像、Compose 和完整数据备份。

## 验证范围

验证覆盖静态资源缓存头、网址粘贴、菜单视口边界、更新通知与草稿保护，以及真实两份生产构建的 Service Worker 安装、等待、激活和多标签页行为。正式发布由 CI 构建镜像和两种架构原生节点包。

移动浏览器仿真不代表真机验收；ARM64 实机安装、长时高负载与公网多节点故障切换不属于本次自动化验证范围。
