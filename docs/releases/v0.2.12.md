# Nexo v0.2.12

## 发布组件

- Server（含 Web）：`ghcr.io/thelinyue/nexo-server:0.2.12`。
- Agent：`ghcr.io/thelinyue/nexo-agent:0.2.12`。
- 两端均有运行时代码变化，部署包包含各自的 Compose、TOML、发布清单和许可证。

## 改进与修复

- Server 与 Agent 修复 HTTPS 服务端口收到明文 HTTP 请求时的跳转，避免错误地按 TLS 处理。
- 更新 Nexo 品牌插画、头像与 PWA 启动层，完善桌面和移动端明暗主题。
- 服务列表改为应用图标网格，支持图标选择、详情浮层、访问及复制反馈、多选管理；图标从 HD-Icons 在线按需加载，无法加载时回退通用图标。
- Server 为服务增加可空 `icon_id` 字段，只接受内置目录中的相对路径；旧客户端更新服务时保留已有图标。现有数据库启动时自动添加字段，Agent 通信格式不变。

## 更新

更新前备份 Server 与 Agent 的完整数据目录、Compose 和自定义 TOML。保留原挂载和节点身份，分别将现有 Compose 中的 Server 与 Agent 镜像标签改为 `0.2.12`，只拉取并重建对应服务：

```bash
docker compose pull nexo-server
docker compose up -d --no-deps nexo-server
curl --fail --max-time 5 http://127.0.0.1:8280/health

# Agent 原部署目录，按实际 Compose 文件名指定 -f
docker compose -f compose.agent.yml pull nexo-agent
docker compose -f compose.agent.yml up -d --no-deps nexo-agent
```

确认原账号可登录、Agent 恢复在线、既有服务可访问。回退时分别恢复原镜像标签及备份；旧版 Server 可忽略新增的数据库列。公网 DNS、公共 ACME、真实设备 PWA 与外网连通性不属于本次本地测试结论。
