# Nexo v0.1.6

Nexo `v0.1.6` 扩展共享网络和站点互联管理，并完善设备删除后的配置保留与批量运维流程。

## 主要变化

- 设备删除后可保留 Tunnel 配置并进入未分配状态，避免误删业务配置。
- 共享网络支持管理员手动声明 CIDR；SiteLink 支持每侧多个网段和 IPv4/IPv6 下一跳。
- 增加 Tunnel 批量分配、启停和删除，以及设备和 SiteLink 的编辑能力。
- 增加逐路由设备、控制面和远端状态展示，并同步 Headscale 节点重命名。

## 升级

升级前请备份完整的 `data/nexo` 和各站点 `data/nexo-agent` 数据目录。将 Server
与 Agent 镜像同时更新到 `0.1.6` 后执行 `docker compose pull` 和
`docker compose up -d`。数据库迁移会自动执行；如需回滚，必须同时恢复升级前的完整数据备份和对应旧镜像。

## 镜像

发布工作流会在本节后附加两个镜像的不可变 SHA256 digest。
