# Nexo v0.1.3

Nexo `v0.1.3` 完善网关控制台与部署配置，提供更完整的站点互联和网关状态反馈。

## 主要变化

- 完善 Subnet Gateway、Site Gateway 和 SiteLink 管理界面。
- 增强设备能力、路由应用状态与错误反馈展示。
- 补充 Server Caddy 默认配置，统一正式部署镜像版本。
- 扩展浏览器发布验收测试。

## 升级

升级前请备份完整的 `data/nexo` 和各站点 `data/nexo-agent` 数据目录。将 Server
与 Agent 镜像同时更新到 `0.1.3` 后执行 `docker compose pull` 和
`docker compose up -d`。

## 镜像

发布工作流会在本节后附加两个镜像的不可变 SHA256 digest。
