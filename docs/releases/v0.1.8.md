# Nexo v0.1.8

Nexo `v0.1.8` 是公网穿透、证书进度和 Cloudflare DNS 托管热修版本。

## 主要变化

- 恢复升级后历史 Tunnel 列表读取，并确保 Web Service 的精确 Host 路由位于泛域名 404 兜底之前。
- Caddy storage 中的根域名和泛域名证书分别识别、展示和续期，不再要求同一张证书同时包含两类 SAN。
- 证书卡显示真实阶段、SAN、签发时间、到期时间、预计续期时间、尝试次数、最近事件和 Caddy 下次重试。
- Caddy 日志同时保留 `msg` 与详细 `error`，并解析 `429`、`Retry-After` 和 `retrying_in`。
- 增加 Cloudflare DNS 托管：只管理 `@` 与 `*` 的 A/AAAA，固定 DNS only，修改前必须预览。
- 同值记录接管原 record ID；缺失记录创建；内容、类型或代理状态冲突需明确确认后替换。
- 后台检测只报告漂移，不覆盖 Cloudflare 中的手工修改；关闭托管默认保留记录。
- ACME 环境从产品界面和写入 API 移除，正式部署固定使用 Production CA。

## 升级与回滚

升级前停止 `nexo-server`，备份 `/opt/stacks/nexo/compose.yml` 与 `/opt/stacks/nexo/data/nexo`。数据库迁移默认不会接管历史 DNS；升级后需在域名设置中主动开启托管、填写公网地址并确认预览。

正式部署使用 `ghcr.io/thelinyue/nexo-server:0.1.8`。本次 VPS 验收只升级 Server；Agent 无需因普通 DNS 同步重新认证。回滚时必须同时恢复旧镜像和升级前数据备份。
