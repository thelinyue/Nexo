# Nexo v0.1.18

Nexo `v0.1.18` 完善官方 Tailscale 客户端访问、设备组网名称和共享子网管理，并更新网络验收工具。本版本同时修改 Server、Web、共享协议和 Agent，需要两端共同升级。

## 网络体验

- 设备显示名称与组网访问名独立保存，组网访问名支持 Headscale MagicDNS 访问。
- 从设备详情编辑检测到的家庭子网，保存后由 Nexo 自动协调路由、Agent 广告、控制面批准和工作空间授权。
- 共享子网统一启用 SNAT，普通客户端无需配置家庭路由器回程路由；IPv4 和 IPv6 转发分别校验。
- 设备离线时保存的网络配置会在上线后继续应用。
- 官方客户端、子网访问和公网服务的自动化验收统一使用 `docker/network-smoke.sh`。

## 升级与发布组件

本次发布 Server 和 Agent：

- `ghcr.io/thelinyue/nexo-server:0.1.18`
- `ghcr.io/thelinyue/nexo-agent:0.1.18`

升级前备份 `./data/nexo` 和 Agent 身份目录。拉取并重建 `nexo-server` 与所有 `nexo-agent`，保留现有节点身份。数据库迁移会在 Server 启动时事务执行；历史 SiteLink 配置需要管理员按升级说明人工清理家庭路由器静态回程路由。

真实移动端登录和家庭 LAN 数据面仍需在目标部署环境验收；自动化测试不替代该项验证。
