# Nexo v0.1.10

Nexo `v0.1.10` 修复 `v0.1.9` 中 Caddy 已加载路由但未把自动证书主题加入管理列表的问题。

## 修复

- 为每个 Cloudflare 自动证书域名显式管理根域名和泛域名证书。
- 重新启用持久化存储中已有证书的选择，并继续由 Caddy 负责签发、退避和续期。
- 自动证书与手动证书并存时保留两类证书加载配置。
- 保持精确 Web Service Host 路由位于泛域名 404 兜底之前。

## 升级与回滚

正式部署使用 `ghcr.io/thelinyue/nexo-server:0.1.10`。从 `v0.1.9` 升级不新增数据库迁移；VPS 只需升级 Server，Agent 无需变更。
