# Nexo v0.1.5

Nexo `v0.1.5` 完成网关路由逐项收敛和资源删除闭环，确保本地业务记录、Headscale 节点以及实际数据面状态一致。

## 主要变化

- 站点、设备、共享网络、站点互联和穿透服务支持按依赖关系删除；删除过程中保留明确的 Pending 状态，完成后才从 API 列表移除。
- 网关按每条路由报告本地应用结果，分别校验 IPv4/IPv6 转发能力；Site Gateway 继续保持双向 LAN 路由和真实源 IP。
- Headscale 对尚未发现的路由独立保持 Pending，并在设备删除完成时同步删除对应 Node，避免旧身份残留。
- 更新迁移 `0012_resource_deletion`，兼容已有数据库并避免重复执行时破坏升级流程。
- Server 和 Agent 镜像、正式 Compose 示例及设备入网 Compose 升级为 `0.1.5`，默认日志时区为 `Asia/Shanghai`。

## 验收

- Rust 格式检查、Workspace 测试、Clippy 警告零容忍和 Web 生产构建通过。
- 第二阶段 Linux Docker 验收通过双向 Site-to-Site、真实源 IP、Tunnel、WebSocket、黑洞恢复、Session 隔离、组件重启收敛和资源删除清理。

## 升级

升级前请备份完整的 `data/nexo` 和各站点 `data/nexo-agent` 数据目录。将 Server
与 Agent 镜像同时更新到 `0.1.5` 后执行 `docker compose pull` 和
`docker compose up -d`。数据库迁移会自动执行；如需回滚，必须同时恢复升级前的完整数据备份和对应旧镜像。

## 镜像
