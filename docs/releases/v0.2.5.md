# Nexo v0.2.5

## 安装与兼容性

**本版本要求 Server 和 Agent 全新安装，不支持从 v0.2.4 或更早版本原地升级。** 两端均有实际代码变化，不能混用旧组件。

- 安装前停止并备份旧部署及完整数据目录；保留旧备份用于回退，不要删除原数据。
- 在独立空目录安装 v0.2.5，可预置新版 `server.toml` / `agent.toml`。不要挂载旧数据库或 Agent 身份目录，也不要照搬旧版 `NEXO_*` 启动环境变量。
- Server 首次启动创建管理员账号；在 TOML 的 `[admin]` 设置初始账号，密码留空时随机生成并在首次创建日志中输出。指定密码至少 6 个字符。
- 登录后配置管理地址、可信代理与公网 IP，创建空间接入密钥，再按页面生成的 TOML 与部署命令接入新 Agent；原有服务和域名需重新配置。
- 新版实例可正常重启、续签和恢复身份。备份时停止对应组件并复制完整持久目录，恢复到空目录并使用同一版本；不要备份 `/run/nexo` 中的临时 Socket。

安装步骤见 [项目说明](../../README.md)与 [配置、备份和恢复](../../docker/README.md)。本次发布不自动更新任何现有部署。

## 新增与改进

- 两端通过 `--config` / `--data-dir` 使用 TOML，首次安全创建中文模板，配置相对路径按 TOML 所在目录解析。
- 管理地址、可信代理 IP 与公网 IP 在管理页面保存，保留管理员权限、来源和 CSRF 校验；保存失败保留输入和原设置。
- 数据库使用当前结构初始化，移除历史兼容迁移；共享密钥接入取代旧设备一次性审批流程，保留身份恢复、续签和每域凭据保护。
- Linux 转发 Socket 使用独立运行目录和受限权限，Compose 为 `/run/nexo` 提供 tmpfs；持久化证书及 Caddy 已应用配置。
- 完善邀请链接、接入配置与部署命令复制，失败可重试或手动选择文本，不重复创建邀请。
- 登录和邀请注册统一紧凑表单，校验失败保留输入并阻止重复提交；用户列表单行展示，更多菜单支持键盘关闭、弹窗返回焦点和完整账号信息。
- 桌面页面充分使用可用宽度，改进移动端、横屏及明暗主题布局。

## 发布组件

- Server（含 Web）：`ghcr.io/thelinyue/nexo-server:0.2.5`
- Agent：`ghcr.io/thelinyue/nexo-agent:0.2.5`

部署包包含两端 Compose 模板、TOML 模板、安装文档与许可证。模板默认使用 `latest`；固定安装本版本时，将两端镜像标签均改为 `0.2.5`。
