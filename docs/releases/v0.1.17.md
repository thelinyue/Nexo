# Nexo v0.1.17

Nexo `v0.1.17` 将设备加入、家庭私网访问、公网服务和域名 HTTPS 整合为一套连续的网络管理流程。本版本同时修改 Server、Web、共享协议和 Agent，需要两端共同升级。

## 一体化网络体验

- 一级“网络”入口统一包含设备、私网访问、公网服务、访问策略和网络设置。
- Nexo Agent 与官方 Tailscale 客户端统一显示在设备列表，并按类型、能力和状态区分。
- 在私网访问中选择 Agent 检测到的网段并确认一次，即可原子完成路由创建、Agent 广告、控制面批准和同工作空间访问授权。
- 普通共享网段默认启用 SNAT，手机等客户端无需为家庭路由器配置回程路由；无 SNAT SiteLink 保留在高级流程。
- Tailscale 的子网路由 SNAT 为节点级设置；同一 Agent 承担 SiteLink 时，其普通共享网段也会切换为无 SNAT。需要保留默认 SNAT 时，应使用独立 Agent 承担 SiteLink。
- 公网 Web 与 TCP 服务使用统一列表和详情 Sheet；Web 服务缺少域名时可原地配置域名，并在返回后保留服务草稿。

## 连接状态与安全边界

- Agent 每 15 秒读取本机 Tailscale 状态，只上报 peer Node ID、活动状态、连接类型和观测时间。
- 路由详情显示 P2P 直连、节点中继、DERP 中继、空闲或未知；超过 45 秒的观测统一显示未知。
- 手动检测只提交设备 ID，由 Server 选择可信 Tailscale 地址并要求 Agent 执行受限 `tailscale ping`。
- OIDC 和 Nexo Auth Key 节点自动归属签发工作空间，未知来源节点继续隔离；密钥明文不持久化。

## 镜像与升级

本次发布：

- `ghcr.io/thelinyue/nexo-server:0.1.17`
- `ghcr.io/thelinyue/nexo-agent:0.1.17`

升级前备份 `./data/nexo` 和 Agent 身份目录。拉取并重建 `nexo-server` 与所有 `nexo-agent`；不要只升级一端。数据库迁移会在 Server 启动时事务执行，连接观测数据不包含公网端点或中继区域。

真实 iPhone 自定义控制服务器登录和家庭 LAN 数据面仍需在目标部署环境验收；自动化浏览器与 Rust 测试不替代该项验证。
