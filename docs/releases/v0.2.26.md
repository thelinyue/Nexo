# Nexo v0.2.26

## 发布组件

本次发布 Server（含管理界面），镜像为 `ghcr.io/thelinyue/nexo-server:0.2.26`。Agent 最近正式版为 0.2.25，独立 VPS 节点最近正式版为 0.2.24。

## 更新内容

- 管理界面统一标题、正文、操作与辅助文字的字号层级。节点卡片的移除、更新和管理按钮使用相同字号与字重，并以颜色区分用途。
- 精简空状态、安装流程与图表中的重复说明。流量图按实际刻度宽度留白，小屏放大文字时仍可查看完整读数。
- 移动导航与服务列表、图标视图切换支持过渡动画，手机搜索和视图切换共用首行。
- 管理员可移除离线节点、删除已绑定服务的节点组。仍有可用入口的服务按剩余绑定调整，失去全部入口的服务停用并保留配置。详情见[多节点管理](../multi-node.md)。

## 升级与回退

先备份现有 Compose、配置及完整 Server 数据目录，包括数据库、证书、密钥和身份文件。使用现有挂载、网络与环境变量，将 Compose 中的 Server 镜像固定为 `0.2.26` 后执行以下命令。

```sh
docker compose pull nexo-server
docker compose up -d --no-deps nexo-server
docker compose exec -T nexo-server nexo --version
curl --fail http://127.0.0.1:8280/health
```

确认版本和健康状态后，检查设备、节点连接及已有服务入口。已安装的 PWA 可通过更新提示加载新版界面。需要回退时，停止 Server，恢复升级前镜像、Compose、配置与配套数据备份，再启动服务。
