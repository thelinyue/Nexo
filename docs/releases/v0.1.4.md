# Nexo v0.1.4

Nexo `v0.1.4` 完善 Web PWA、网络互联工作台和穿透服务稳定性，并统一时间字段与容器日志时区。

## 主要变化

- Web 支持安装为 PWA，应用壳可缓存，`/api/` 请求始终联网，不缓存账户和网络数据。
- 网络互联页面按站点集中展示网关设备、共享网络、站点互联和静态路由确认。
- 穿透服务和域名与 HTTPS 的界面、错误日志使用统一产品术语。
- API 时间字段统一为 Unix 秒；历史数据库通过迁移 `0011_time_consistency` 一次性修复字段类型。
- Tunnel 数据连接启用 TCP keepalive，降低长期空闲连接被网络设备回收后的恢复延迟。
- Server 和 Agent 镜像、正式 Compose 示例及设备入网 Compose 升级为 `0.1.4`，默认日志时区为 `Asia/Shanghai`。

## 升级

升级前请备份完整的 `data/nexo` 和各站点 `data/nexo-agent` 数据目录。将 Server
与 Agent 镜像同时更新到 `0.1.4` 后执行 `docker compose pull` 和
`docker compose up -d`。数据库迁移会自动执行；如需回滚，必须同时恢复升级前的完整数据备份和对应旧镜像。

## 镜像
