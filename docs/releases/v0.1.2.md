# Nexo v0.1.2

Nexo `v0.1.2` 简化了正式 Docker 部署：Server 无需环境变量即可启动，Agent
只需要目标 Server 地址和 Web 生成的一次性入网 Token。此版本仍仅发布
`linux/amd64` Docker 镜像。

## 主要变化

- Web“添加设备”可以设置设备名称和站点，并生成可直接运行的 Agent Compose。
- Agent 自动使用 Server 主机的 `9890` 控制端口和 `9891` Tunnel 数据端口。
- 设备能力、内置组件路径和数据目录不再出现在普通用户的 Compose 中。
- 修正 Server 默认下发本机地址后导致远端 Agent Tunnel 无法连接的问题。

## 安装

Server 的 Compose 不需要 `.env`：

```bash
docker compose up -d
docker compose exec nexo-server nexo bootstrap-code
```

打开 `http://<Server-LAN-IP>:8280` 完成初始化，再从 Web“添加设备”复制 Agent
Compose。完整配置、端口要求和环境变量说明见仓库 README。

## 升级

升级前必须备份完整的 `data/nexo` 和各站点 `data/nexo-agent`。将 Server 与
Agent 镜像同时更新到 `0.1.2` 后执行 `docker compose pull` 和
`docker compose up -d`。需要回滚时必须同时恢复升级前的完整数据备份。

## 本版不包含

Exit Node、默认路由、UDP Tunnel、TLS passthrough、NAT 转换、重叠网段转换、
跨租户共享和 Caddy 路径路由。
