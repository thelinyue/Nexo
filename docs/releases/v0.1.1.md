# Nexo v0.1.1

Nexo（联巢）的首个可安装公开版本，把分散设备、共享网络、站点互联和公网访问集中到
同一个 Web 管理界面中。此版本仅发布 `linux/amd64` Docker 镜像。

`v0.1.1` 修正了 `v0.1.0` 标签发布时发现的基础镜像摘要错误；`v0.1.0` 未生成
GitHub Release 或可安装镜像。

## 主要能力

- 一次性设备入网与 Web 审批，Agent 可加入任意 Nexo Server。
- 双向 LAN 站点互联、共享本地网络和真实源 IP 保留。
- TCP Tunnel，以及 HTTP/HTTPS Web Service。
- Cloudflare DNS-01 泛域名证书和手动证书模式。
- 管理员初始化、Session、CSRF、密码恢复和审计记录。

## 安装

下载 Release 中的 `nexo-v0.1.1-docker.tar.gz`，解压并编辑 `.env` 后运行：

```bash
docker compose up -d
```

需要在其他站点安装 Agent 时使用 `compose.agent.yml`，并让其中的地址指向目标
Nexo Server。完整步骤与备份、恢复说明见仓库 README。

## 升级

从测试构建升级前先备份 Nexo 持久化目录。数据库升级后只能连同对应备份回滚，
不能直接降级二进制。

## 本版不包含

Exit Node、默认路由、UDP Tunnel、TLS passthrough、NAT 转换、重叠网段转换、
跨租户共享和 Caddy 路径路由。
