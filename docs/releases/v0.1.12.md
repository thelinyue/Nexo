# Nexo v0.1.12

Nexo `v0.1.12` 修复公网域名检测、Web Tunnel 就绪判断和官方 Tailscale 客户端授权入口。

## 新增与修复

- 泛域名 DNS 检测使用具体的 `nexo.<domain>` 探针，并在启动后台任务中修复升级前保存的错误快照。
- Web Tunnel 按显式绑定的公网域名判断状态；HTTP 不再等待无关 HTTPS 证书，HTTPS 会分别检查路由、根证书和泛域名证书。
- 官方 Tailscale 客户端配置不再提供无效的固定 `/register` 地址，由客户端发起带本次注册上下文的一次性授权页面。
- 增加相关服务端单元测试和浏览器验收覆盖。

## 升级与回滚

正式部署使用 `ghcr.io/thelinyue/nexo-server:0.1.12` 和 `ghcr.io/thelinyue/nexo-agent:0.1.12`。升级时 Server 会在后台刷新可识别的旧版泛域名 DNS 快照，不阻塞服务启动。
