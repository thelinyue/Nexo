# Nexo v0.2.28

## 更新内容

- 修复内网穿透在页面并行加载大量资源时出现成批 502 和已有连接中断的问题。每条设备数据连接允许 64 条业务流同时转发，并为流回收和节点探测预留空间。每个服务监听器为刚接入的连接等待名额最多 10 秒。
- 服务列表和详情中的成功提示会在 5 秒后消失。再次操作成功会重新计时，失败原因仍可在原处查看。

## 发布与升级

本次发布 Server 镜像 `ghcr.io/thelinyue/nexo-server:0.2.28` 和 Linux x86_64、ARM64 独立 VPS 节点包。现有 Agent 0.2.27 可配合新版入口使用。

升级前备份 Compose、数据库、配置、证书和节点身份。将 Server 镜像固定到 `0.2.28`，沿用现有挂载、网络与环境变量。

```sh
docker compose pull nexo-server
docker compose up -d --no-deps nexo-server
docker compose exec -T nexo-server nexo --version
curl --fail --max-time 5 http://127.0.0.1:8280/health
```

Server 上线后可从管理界面逐个更新独立节点。检查设备重新连接，并从实际公网入口打开应用，确认资源与 WebSocket 均能加载。需要回退时，恢复升级前的组件版本、配置和配套数据备份。
