# Nexo v0.1.15

Nexo `v0.1.15` 是 Server-only 正式修复版本。Server 更新 Headscale Supervisor
和访问控制策略校验；Agent 没有代码变化，继续使用 `0.1.14`，无需升级。

## 修复

- Headscale 连续配置通知现在按单调重启代次合并，残留通知不会停止新进程；异常退出仍会指数退避重启。
- 相同 OIDC issuer 更新幂等，不会重写配置或触发重启。
- 访问控制校验明确区分 `valid`、`invalid` 和 `unavailable`，隐藏内部地址与底层网络栈。
- 策略服务暂不可用时禁止保存未经成功校验的规则，并在服务恢复后由后台自动重试。

## 镜像与升级

本次仅发布：

- `ghcr.io/thelinyue/nexo-server:0.1.15`

Agent 保持：

- `ghcr.io/thelinyue/nexo-agent:0.1.14`

升级前备份 `./data/nexo`，只拉取并重建 `nexo-server`。不要为本版本创建或部署
Agent `0.1.15`。本版本无数据库迁移，回滚时可恢复 Server `0.1.14`；旧版
Supervisor 的连续通知竞态也会随回滚恢复。
