# Nexo v0.1.13

Nexo `v0.1.13` 增加 Nexo 账号与 Headscale OIDC 账号映射，并支持官方 Tailscale 客户端通过 OIDC 完成授权注册。

## 新增与修复

- 增加固定 OIDC 签名密钥、账号映射和撤销状态同步，私钥不会通过 API、日志或 Web 返回。
- 增加 OIDC 登录和授权回调，以及官方 Tailscale 客户端注册入口。
- 增加迁移 `0020` 和相关服务端、浏览器验收覆盖。
- 收敛认证、Headscale、策略及公网入口处理，改善部署失败时的中文错误提示。

## 升级与回滚

正式部署使用 `ghcr.io/thelinyue/nexo-server:0.1.13` 和 `ghcr.io/thelinyue/nexo-agent:0.1.13`。数据库迁移只向前执行；升级前请备份完整数据目录，回滚时必须同时恢复对应版本的数据备份和旧镜像。
