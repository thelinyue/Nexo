# Nexo v0.2.2

本次仅发布 Server。Agent 没有代码变化，继续使用 `0.2.0` 镜像。

## 变化

- 添加 Agent 时，Docker Compose 模式直接显示可保存的 `compose.yml` 配置文件，预填 Server 地址和一次性入网凭证。
- `docker run` 模式直接显示可执行的单条命令，不再显示 Bash 部署脚本。
- 预览默认展开，复制按钮与提示文字随部署方式变化。

## 升级与发布组件

本次仅发布 Server：

- `ghcr.io/thelinyue/nexo-server:0.2.2`

Agent 保持：

- `ghcr.io/thelinyue/nexo-agent:0.2.0`

本版本没有数据库迁移。升级前备份现有 Server 数据和 Compose 配置。在现有部署配置中，只将使用 Server 镜像的服务改为 `ghcr.io/thelinyue/nexo-server:0.2.2`，拉取并重建这些服务。不要拉取或重建 Agent。
