# Nexo v0.2.6

## 发布组件

- 本次仅发布 Server（含 Web）：`ghcr.io/thelinyue/nexo-server:0.2.6`。
- Agent 无运行时代码变化，继续使用 `ghcr.io/thelinyue/nexo-agent:0.2.5`，不发布 v0.2.6 Agent 镜像或部署包。
- 下载包只包含 Server Compose、Server TOML、发布清单与许可证；包内镜像固定为 `0.2.6`。

## 改进与修复

- 首次创建管理员支持 `NEXO_ADMIN_USERNAME` / `NEXO_ADMIN_PASSWORD`，非空值逐项优先于 TOML，空值回退到 TOML；已有账号不会被覆盖。
- 容器日志明确区分随机密码首次输出、指定密码创建成功和已有账号跳过初始化；指定密码不输出明文。
- 添加 Agent 页面一次复制即可保存 TOML 并启动容器，Compose 方式同时保存 `compose.agent.yml`。配置以权限 `0600` 创建，拒绝覆盖已有文件或符号链接，凭据不传入容器环境变量。
- 桌面表单居中显示，长内容内部滚动，底部取消和顶部关闭复用未保存确认及提交锁；完善域名空状态、添加表单和窄桌面布局。
- Server 默认运行目录由容器内部管理，部署模板不再要求额外挂载 `/run/nexo`。

## 安装与更新

已有 **v0.2.5** 部署可以保留数据、配置和 Agent 身份，本次没有数据库结构或通信协议变化。先停止并备份 Server 完整数据目录及 Compose，再将现有 Compose 中的 Server 镜像改为 `ghcr.io/thelinyue/nexo-server:0.2.6`，只拉取并重建 Server：

```bash
docker compose pull nexo-server
docker compose up -d --no-deps nexo-server
docker compose ps nexo-server
docker compose logs --tail=100 nexo-server
```

保留现有自定义配置和挂载；不替换 Agent 容器或身份目录。确认 `/health` 正常、原账号可登录、Agent 恢复在线且既有服务可访问。回退时停止新版 Server，使用 v0.2.5 镜像和更新前备份。

从 **v0.2.4 及更早版本** 安装仍须沿用 v0.2.5 的全新安装要求：备份旧部署，在独立空目录安装 Server v0.2.6 与 Agent v0.2.5，不导入旧数据库或身份。新安装说明见 [项目说明](https://github.com/thelinyue/Nexo/blob/v0.2.6/README.md)，配置及恢复说明见 [容器文档](https://github.com/thelinyue/Nexo/blob/v0.2.6/docker/README.md)。

本次发布不自动更新任何现有部署。公网 DNS / Cloudflare DNS-01、公共 ACME、HTTP/3、真实手机系统剪贴板、跨主机恢复与长时负载不属于本次验收结论。
