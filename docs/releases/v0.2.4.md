# Nexo v0.2.4

本版本同时更新 Server、Web 和 Agent。Server 与 Agent 均有实际代码变化，部署时需要共同升级。

## 新增与改进

- 支持 UDP 隧道，并改进公网协议与回源协议的配置和状态展示。
- 增加 VPS 反向代理服务、Web 服务密码保护、流量统计与用量配额管理。
- 增加内网重定向，并改进 Agent 入网、服务配置和工作区导航。
- 首次启动时自动创建管理员账号；可通过 `NEXO_ADMIN_USERNAME` 和 `NEXO_ADMIN_PASSWORD` 设置账号。未设置密码时会生成随机密码，并只在首次创建时输出到 Server 日志。

## 升级与发布组件

本次发布以下镜像：

- `ghcr.io/thelinyue/nexo-server:0.2.4`
- `ghcr.io/thelinyue/nexo-agent:0.2.4`

升级前备份 Server 数据和部署配置。保留现有 v0.2.x 数据目录；Server 启动时会自动补齐新增的 SQLite 表和字段，不需要清空数据目录。更新 Compose 或 `docker run` 配置中的 Server、Agent 镜像版本后，拉取并重建这两个服务。不要把 v0.1.x 数据目录用于 v0.2.x；v0.1.x 到 v0.2.x 仍要求全新安装。
