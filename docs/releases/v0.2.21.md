# Nexo v0.2.21

## 发布组件

- Server（含 Web 与数据库迁移）：`ghcr.io/thelinyue/nexo-server:0.2.21`。
- 独立节点：Linux x86_64、ARM64 原生安装包，节点版本 `0.2.21`。
- Agent 使用的协议与运行逻辑无变化，不发布新镜像或部署包。已有 Agent 无需随本版升级。

## 更新内容

- 节点添加者与管理员可设置整台节点的月流量额度，获授权用户只能查看。默认不限制，支持添加时预设和详情中修改。
- 所有用户经过节点的穿透、反向代理上传下载合计，按北京时间自然月重置。旧节点升级后开始计量，不追溯历史流量；用户穿透额度继续独立生效。
- 详情显示已用、待结算占用、剩余额度与重置时间。预算在回复前持久化，重复结算不重复扣减，失联未结算额度不会因重启恢复。
- 额度用尽时暂停转发并关闭已有连接，管理通道保持在线。节点组穿透按现有规则选择健康授权备用；固定单节点服务与反向代理暂停。提高或取消限制、进入下月后重新检查健康并恢复入口，客户端需重新连接。
- 反向代理增加回环 TCP 计量桥，保留 Host、HTTPS 回源 SNI、证书校验、访问认证和 WebSocket。计量包含 HTTP 头与 HTTPS 回源 TLS 字节，不含节点管理流量，可能与运营商账单不同。
- 节点维护按服务切流：有健康备用时撤出受管 A 并等待 TTL，无备用时保留符合当前配置与授权的受管 A。节点安装确认与逐服务恢复分开，单个故障后端不再阻塞其他服务恢复。
- 精简额度设置与暂停提示，保留连接中断、升级要求及计量说明。

## 更新和回退

升级前停止 Server，备份完整数据目录、Compose 与自定义配置。本版增量创建节点额度、月用量、预算表并更新入口资格视图；保留账号、设备身份与服务绑定。

保留原挂载、网络与环境变量，将 Server 镜像标签固定为 `0.2.21`，仅更新 Server：

```bash
docker compose pull nexo-server
docker compose up -d --no-deps nexo-server
curl --fail --max-time 5 http://127.0.0.1:8280/health
```

Compose 不在当前目录时使用 `-f <文件路径>`。确认 Server 健康、Agent 重新连接及身份与服务绑定保留。Agent 不需重建。

需要限制独立节点流量时，核对节点包与 `SHA256SUMS`，使用现有节点更新任务或更新助手升级至 `0.2.21`，保留节点身份与配置。旧节点可继续原有转发，但升级前不能启用额度限制。修改额度会撤销旧连接预算，客户端需重新连接。

回退时停止 Server，恢复原镜像、Compose 与完整数据备份。计量节点一并回退前须取消节点限制；旧节点不支持额度执行。

## 验证范围

本地覆盖额度权限与 CSRF、非法输入、并发预算、部分与失败写入、重复结算、失联与重启、跨月、额度调整及用户额度独立生效。真实 mTLS/Yamux 与 Caddy 验证穿透、HTTP/HTTPS 回源、WebSocket、长下载额度用尽、证书校验与访问认证。维护与 DNS 恢复包含单入口、多入口、故障后端和外部记录保护回归。

Web 验证覆盖桌面、手机竖屏与横屏、只读权限、草稿保留、失败重试和取消限制。移动浏览器仿真不代表真机验收；ARM64 实机与生产公网新建额度服务不属于自动化验收范围。
