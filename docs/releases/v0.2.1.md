# Nexo v0.2.1

Nexo v0.2.1 改进 Agent 入网部署流程，并完善 latest 稳定标签管理。本次只发布 Server；Agent 没有代码变化，继续使用 `0.2.0`。

## 主要变化

- 添加 Agent 时可生成 Docker Compose 或 `docker run` 命令，并预填 Server 地址与一次性入网凭证。
- 入网凭证只在弹窗内存中保留；命令复制失败时可展开手动复制，凭证过期后需要重新生成。
- Compose 示例使用 latest 稳定标签。发布流程按组件更新 latest，并验证目标镜像摘要，避免历史版本回退覆盖。

## 升级与发布组件

本次仅发布 Server：

- `ghcr.io/thelinyue/nexo-server:0.2.1`

Agent 保持：

- `ghcr.io/thelinyue/nexo-agent:0.2.0`

本版本没有数据库迁移。升级前按部署维护流程备份 `./data/nexo`。在现有 `compose.yml` 中只将 Server 镜像改为 `ghcr.io/thelinyue/nexo-server:0.2.1`，保留现有挂载、端口和环境配置，然后只更新 Server：

```bash
docker compose pull nexo-server
docker compose up -d --no-deps nexo-server
```

不要为本版本拉取或重建 Agent；已有 Agent 身份与连接继续使用 `0.2.0`。
