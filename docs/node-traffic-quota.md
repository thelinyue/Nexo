# 自建节点月流量限制

普通用户可以为自己添加的 VPS 节点设置月额度，管理员也可以调整。获得节点使用权的其他用户只能查看。设置额度不会授予审批、分配节点、更新或移除节点的权限。

在添加节点时选择“不限制”或填写正整数 GiB；已有节点在详情的“本月流量”中选择“设置流量限制”。旧节点须先升级至支持流量计量的版本，才能启用限制。添加时预设的额度在新版节点接入后生效。

## 计量与恢复

- 按北京时间自然月，所有用户经过该节点的内网穿透和反向代理上传、下载合并计量。
- 包含转发的 HTTP 头和 HTTPS 回源 TLS 字节，不包含节点管理流量，不追溯升级前的历史流量；计量结果与运营商网卡账单可能不同。
- 用户穿透额度和节点额度分别生效；反向代理消耗节点额度，但不消耗用户穿透额度。重置用户统计不会恢复节点额度。
- “待结算占用”包含正在使用和失联未结算的预算。为避免重启后重复花费，失联预算继续占用本月额度，不自动归还。
- 额度用尽后关闭现有转发并拒绝新转发，节点管理通道保持在线。节点组穿透服务可按现有规则切换健康授权备用节点，固定单节点服务和反向代理暂停。
- 每月 1 日北京时间零点恢复；提高或取消限制也会恢复入口。修改额度会撤销旧预算连接，客户端需重新连接。策略通过节点控制快照同步；当前控制器通常在两秒内下发变化，节点轮询周期为十秒。

## 实现与接口

`GET /api/v1/nodes/{id}/traffic/quota` 返回月额度、已确认用量、待结算占用、剩余额度、周期和能力状态。`PUT` 接受 `{"monthly_limit_bytes": 107374182400}`，取消限制使用 `null`；写入沿用会话认证、CSRF、节点归属检查和操作记录。内置节点不提供此配置。

控制器在 SQLite 事务内检查服务授权、配置版本、额度修订和月份，并在回复前持久化小批量预算。节点仅按成功写入的字节结算；累计报告支持重复发送，最终报告只返还未使用部分，迟到报告只能影响原月份。预留占满时等待预算归还，不能把暂时没有预算当作实际耗尽。

穿透在节点业务转发流中计量。反向代理使用只监听回环地址的 TCP 计量桥，Caddy 保留原目标的 Host、HTTPS 回源 SNI、证书校验、访问认证和 WebSocket，仅改变连接地址。

此功能需要更新管理 Server 和独立节点运行代码，不要求更新 Agent。正式发布仍须按实际组件代码变化分别判断；本文不指定新版本号或部署操作。
