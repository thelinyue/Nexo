## 验证边界

- 公网 DNS、真实 Cloudflare 权限与 DNS-01、公共 ACME 签发未执行；内部 CA 和测试凭据不代表公网验收通过。
- 手机采用浏览器移动仿真，未在真实 Android / iOS 系统剪贴板上验收。WebKit 的失败交互已覆盖，真实剪贴板内容读回未验证。
- 本机 HTTP/3 和公网 UDP 443 未验证。真实外网 RDP、长时高负载、跨地域丢包与吞吐没有测量；并发和大文件功能检查不代表正式性能对比，也不宣称 tmpfs 提高吞吐。
- 完整目录恢复在同机空目录执行，跨主机恢复、真实 Cloudflare 凭据恢复后的公网续签需在相应环境单独验收。
