# Nexo 使用指南

本指南面向已完成 [快速部署](../README.md#快速部署) 的用户。默认示例对应 latest 稳定版；界面开发分支新增的功能可能尚未发布。

管理员可在服务页点击「添加反向代理」，无需 Agent 即可访问 VPS 上的 HTTP/HTTPS 应用，详见 [VPS 反向代理](reverse-proxy.md)。反代不计入穿透流量统计和额度。

## 服务与 Agent

首次登录后默认进入“首页”，已有深链接和会话内标签优先恢复。桌面首页标签固定保留；手机底栏提供“首页、服务、设备、域名、我的”，详情页通过返回入口导航。在“设备”页面点击添加，填写 Server 地址与设备名称。Compose 直接复制原生 YAML 到 NAS 的 Compose 项目，或保存为 `compose.agent.yml` 后启动；docker run 直接复制单条命令到 Linux / NAS 终端执行。两种方式均已内嵌连接参数，不需要安装脚本或单独保存 TOML，要求 Agent v0.2.7 及以上。启动后在“最近接入”查看设备状态。配置含接入密钥，请勿分享。每个空间共用一把长期接入密钥，可部署到多台主机；每台主机必须使用独立数据目录。设备身份由独立私钥和证书认证，设备识别码可在详情复制。正常重启请保留原数据目录和 Server 地址，身份丢失时从原设备详情发起恢复；跨版本安装要求见对应发布说明。新设备通过空间共享密钥接入，仅身份恢复保留申请与审批。

每台 Agent 可以访问同机或其网络可达范围内的应用。目标地址从 Agent 所在主机理解：`127.0.0.1` 指 Agent 主机，局域网另一台设备应填写其内网地址。Docker Compose 默认使用 host 网络。

| 页面 | 用途 |
| --- | --- |
| 首页 | 当前空间概览、流量趋势与待处理事项 |
| 服务 | 创建、编辑、启停、批量操作、复制公网地址 |
| 设备 | 共享密钥接入、在线状态、身份有效期、关联服务和身份恢复 |
| 域名 | 域名配置、证书与运行日志 |
| 我的／账号设置 | 本人账号与登录会话；管理员还可进入用户管理 |

### 访问规则

创建或编辑网页服务时，展开「高级设置」可配置访问规则和内网重定向。访问规则支持「公开访问」或「认证访问」，默认公开。认证密码支持 4–16 位字母、数字或符号，不含空格；编辑时留空保留原密码，切回公开会清除密码。TCP 服务暂不支持密码认证。

访客输入密码后，同一浏览器可在 24 小时内访问该服务，不同服务分别认证。修改密码、切换规则、修改入口域名、关闭或删除服务会使旧认证失效。HTTP 不加密，建议使用 HTTPS。

开启内网重定向后，符合跳转条件的网页导航免密码直达内网；其他公网请求仍受访问规则保护。跳转依据访客与绑定 Agent 的公网 IPv4 是否相同，不代表严格验证同一局域网；API 和 WebSocket 不因此免认证。内网直连的访问权限由目标应用和网络控制。

### 首页与流量

首页展示当前空间的服务、设备和域名摘要，以及可进入详情处理的问题。配置已加载、DNS 已解析和隧道运行中各自表示对应状态，不代表已经完成外网可达性验证。

普通用户只能查看自己的流量，并可选择全部隧道或单条隧道。管理员默认查看全部用户合计，可搜索并选择单个用户，再筛选其隧道；进入代管空间时初始选中该用户。流量筛选不改变资源管理空间，页面明确标注资源摘要和待处理事项的归属。停用用户保留历史；删除用户及空间会清理对应统计。

流量面板顶部显示“今日已用、本周已用、本月已用”，按北京时间（UTC+8）的自然日、周一开始的自然周和自然月计算，包含全部隧道的双向流量。这三项只跟随用户选择，不受单隧道及趋势时间筛选影响，每 5 秒刷新。日汇总保留 90 天，分钟趋势清理不影响当月用量。仅统计当前实例实际采集的数据；未采集时段无法补回，界面显示统计起点及不完整提示。

管理员选择具体用户后，可在“用量概览”右侧点击“重置统计”，确认目标后将该用户所属空间的用量归零，从重置时刻继续累计。趋势历史、实时速率和隧道连接保留；普通用户不能重置，不提供全部用户一键重置。重置需要管理员会话与 CSRF 校验，并记录操作者、目标用户及时间。重置后页面显示最近重置时间；全部用户合计也按各空间重置后的用量相加。重置清除该空间保留的日用量汇总且不可撤销。

用量只读接口为 `GET /api/v1/traffic/usage` 和 `GET /api/v1/admin/traffic/usage`；管理员接口可传 `user_id`，不支持隧道和图表时间参数。重置接口为 `POST /api/v1/admin/traffic/reset`，JSON 请求体必须包含 `user_id`。

“发往内网”是请求方向，“返回公网”是响应方向。速率每 5 秒采样，历史保留 7 天；支持最近 1 小时、24 小时、7 天，分别按 1 分钟、5 分钟、1 小时展示平均速率。首页不可见时暂停刷新，恢复后重新读取。图表可触摸查看，也可用时间滑块和键盘选择数据点；断点表示未采集，零值表示已采集但没有流量。

统计仅包含 Server 实际转发的隧道数据，包括应用协议数据，不含 mTLS/Yamux 开销、局域网直连或未进入隧道的 Caddy 响应。Server 每分钟保存统计，正常退出会保存剩余数据；正常写盘条件下，异常退出可能丢失最后约一分钟记录，不可用作运营商流量账单或计费依据。

### 用户月流量限制

管理员在“我的 → 用户管理 → 账号设置 → 流量限制”为指定用户设置正整数 GiB 月额度，也可选择“不限制”。默认所有用户均不限额，管理员本人也能设限。限制按所属空间全部隧道的双向流量合计计算，每月 1 日北京时间零点恢复，不结转余额。

首页三张用量统计卡下方展示独立的“本月流量额度”、已消耗、剩余量与恢复时间。普通用户只读自己的额度；管理员选定具体用户后查看对应额度。额度从该功能首次上线起计量，不追溯旧统计；不限额期间也记录消耗，之后设限时计入当月额度。

额度耗尽会拒绝新连接并断开现有转发，账号仍可登录、Agent 保持在线。提高额度、取消限制或进入下月后允许重新连接，隧道原有开关和配置保留。降低额度至已消耗量及以下会立即停止转发，保存前显示明确提示。

“重置统计”仅清空可重置的今日、本周、本月统计，保留趋势历史，**不会恢复月额度**。例如额度 100 GiB、已消耗 80 GiB，重置统计后仍剩 20 GiB；需要恢复可用量时由管理员提高额度或取消限制。改名、停用、删除单条隧道均不清除额度消耗，删除用户及空间时清理对应记录。

额度只计算经过 Server 的 TCP／HTTP／HTTPS 应用数据，不含局域网直连、控制与加密传输开销、未进入隧道的响应。正常运行时按实际成功写入实时扣减；每分钟落盘，正常退出保存剩余数据。异常退出可能少计最后约一分钟，适用于运行管理，不作为计费依据。

个人只读接口为 `GET /api/v1/traffic/quota`；管理员使用 `GET /api/v1/admin/traffic/quota?user_id=...` 查询、`PUT` 同一地址修改。写入 JSON 为 `{"monthly_limit_bytes":正整数字节数}`，显式传 `null` 表示不限制；修改要求管理员会话和 CSRF，并记录审计。

### TCP、UDP 与 TCP+UDP 服务

选择 Agent、填写本地地址和端口。公网端口留空时在 `20000–29999` 中自动分配，也可指定此范围内未被使用的端口。按选择的协议放行分配的公网 TCP/UDP 端口，然后使用支持该协议的客户端从外网访问页面给出的地址。

TCP+UDP 使用同一 Agent、内网地址、内网端口和公网端口，分别显示两种协议状态；其中一种故障时另一种继续工作。远程桌面可选择 TCP+UDP、电脑内网 IP 和 3389，再用 `Server地址:公网端口` 连接。目标电脑需已启用远程桌面。UDP 就绪只表示转发配置和通道可用，不表示应用健康。

UDP 数据通道需额外放行 Server `9891/udp`。数据报最大 65,507 字节；会话空闲 5 分钟回收，回收后客户端再次发送可重建，不保证内网主动推送可达。流量按 Server 成功提交的载荷计数，不包含分片头及 QUIC 开销，不代表对端实际收到。

若管理域名使用 Cloudflare 等 HTTP 代理，TCP 访问需要使用直达 Server 的公网 IP 或 DNS 名称；普通 HTTP 代理不能承载任意 TCP Tunnel。

### HTTP / HTTPS 服务

先添加并验证域名，再选择协议、Agent、本地目标和服务子域名。公网 HTTPS 在 Server 的 Caddy 终止，本地应用默认使用 HTTP；例如访问 `https://app.example.com`，可回源到 Agent 的 `127.0.0.1:8080`。支持 WebSocket。

服务只有在 Agent 控制与数据连接、本地目标探测、公网监听和相应 Caddy 路由就绪后才显示正常，HTTPS 还需要有效证书。修改目标、停用或删除服务会关闭旧连接；客户端需自行重连。删除 Agent 会撤销身份并停用关联服务，远端应用文件不受影响。

短时网络中断后 Agent 自动重连；已经断开的应用连接不会续传。缺少数据通道时 Web 入口可能返回 `503`，未知主机名返回 `404`。排查方法见 [容器说明](../docker/README.md#常见问题)。

### 内网重定向

HTTP/HTTPS 服务可单独开启“内网重定向”，默认关闭。跳转地址直接使用服务的本地目标和端口，无需另填地址；例如本地目标 `192.168.1.10:8080` 默认跳转到 `http://192.168.1.10:8080`。修改本地目标后，跳转地址随之更新。公网 HTTPS 不代表本地应用也提供 HTTPS，跳转协议跟随实际回源协议。

开启时，本地目标必须填写浏览器可直接访问的私有 IPv4 或 IPv6 ULA。`127.0.0.1`、`::1`、主机名和公网 IP 无法开启内网重定向；关闭开关仍可正常使用这些回源地址。改为 TCP 会自动关闭重定向。

当浏览器与该服务的在线 Agent 使用同一公网 IPv4 出口时，打开服务域名会收到不缓存的临时跳转，原路径和查询参数保留。只处理携带页面导航 Fetch Metadata 的 GET/HEAD 请求；API 请求、WebSocket 和无法识别的请求继续穿透。普通公网 HTTP 域名在 Chromium 等浏览器中不会发送这些导航头，因此会继续穿透；需要自动跳转时建议使用 HTTPS 服务。配置及出口变化在下一次成功的 Caddy 协调中生效，正常约 5 秒；网络黑洞可能先等待 45 秒心跳超时。

此功能要求浏览器和 Agent 控制连接直接到达 Server，不读取 `X-Forwarded-For` 等转发头。Cloudflare 仅做 DNS 解析可用，橙云、其他前置代理、IPv6 出口或不同出口不在自动识别范围内。相同公网出口不保证内网互通，运营商共享出口、访客 Wi-Fi 和隔离网段可能误判，不能以此替代应用认证。

内网目标的可达性、登录和证书由应用自身负责，公网 HTTPS 证书不会覆盖内网 IP，原域名登录状态也不会迁移。跳转后目标不可达时无法自动返回穿透，请关闭该服务的开关。Server 重启后等待 Agent 重新认证才会恢复跳转规则。


## 域名与自动证书

1. 在“域名与证书”添加自己拥有的域名，例如 `example.com`。
2. 按页面要求添加 `_nexo-verification.example.com` TXT 记录并验证归属；使用 Cloudflare 时，也可提交该域名的受限 Token 完成验证。
3. 在 DNS 服务商为根域名 `example.com` 和泛域名 `*.example.com` 添加解析，指向 Server 公网 IP：A 使用 IPv4，AAAA 仅使用可达的 IPv6。Cloudflare 凭据不会自动创建这些记录。
4. 默认 HTTP-01 为服务主机名单独签发证书，需要公网 TCP 80、443 可达。Cloudflare DNS-01 支持泛域名证书，无需入站验证端口，但用户访问 HTTPS 仍需能到达 Caddy。
5. 在域名详情查看证书和运行日志。访问解析由 DNS 服务商管理，Nexo 不检查解析结果。

Cloudflare Token 只授予所需 Zone 的 Zone Read、DNS Edit；支持传统、`cfut_`、`cfat_` 格式。每个域名独立保存凭据。选择 DNS-01 时，同级服务共用泛域名证书，多级子域名按直接父域复用，根域名另行管理。

Caddy 负责证书签发、续期及退避重试，刷新页面不会触发额外申请。旧证书仍有效时，页面同时保留续期错误和下次重试时间。不要删除证书目录强制重试，以免触发签发限额。

## 多用户分享

管理员进入“管理 → 用户管理”生成邀请链接，受邀人自行设置用户名和密码。邀请仅可使用一次，7 天到期，可随时撤销；没有公开注册入口。每位用户拥有独立工作空间，自行管理 Agent、服务、域名和证书。已验证域名的父子范围不能跨空间重叠，完整服务主机名全局唯一。

系统只有一位管理员，由 Server 首次启动在空账号库中自动创建。启动前可填写 `server.toml` 的 `admin.username`、`admin.password`；用户名默认 `admin`，未设置或为空的密码自动生成，仅在创建成功时输出到终端或容器日志。使用该账号直接登录，网页不再创建管理员。已有账号不受初始配置变化影响，遗失密码时使用下文恢复流程。邀请只能创建普通用户，不支持修改角色。管理员可修改所有账号的用户名，改名会撤销该账号的全部登录会话和密码恢复码，用户与资源 ID 保持不变。管理员自己的用户名修改成功后需用新名字重新登录；自身密码和登录会话可直接从管理员卡片管理。管理员不能被停用或删除。

管理员可从用户卡片进入任意空间进行维护；账号与安全始终操作管理员本人，资源审计同时记录实际操作者和目标空间。停用用户立即吊销登录会话、密码恢复码和待入网凭证，断开转发与 Agent 连接并拒绝重连。服务开关和地址保留，重新启用后恢复此前开启的服务。

普通用户忘记密码时由管理员生成 15 分钟有效的单次恢复链接。管理员仍可用 Server 本机命令恢复账号。邀请与恢复链接仅展示一次，请通过可信渠道发给本人；页面读取后会清除地址栏中的凭据。

删除普通用户时需输入当前用户名确认，会永久删除账号、工作空间、Agent 身份、服务、域名和入网凭证，并立即关闭转发及 Agent 连接；无需事先停用。审计记录保留，已使用的邀请不会再次生效。此操作不删除远端 Agent 主机上的应用文件。域名专属 Cloudflare 凭据在 Caddy 的运行配置与已保存配置均不再引用后清理；失败时页面提示清理待完成，后台与重启后会继续重试，共享证书缓存仍由 Caddy 管理。


## 账号与设备恢复

普通用户忘记密码时联系管理员生成单次恢复链接；管理员忘记密码时，在 Server 主机运行本地恢复命令。设备证书过期、私钥丢失或身份损坏时，从原 Agent 详情页发起身份恢复，保留原设备 ID 和服务绑定。

完整命令和注意事项见 [账号与设备恢复](../docker/README.md#账号设备恢复与域名接入)。不要通过删除原 Agent、清空数据目录或重新初始化 Server 来处理身份故障。

## 开发者接口

Agent 资源继续使用 `/api/v1/devices`，服务使用 `/api/v1/tunnels`，域名使用 `/api/v1/public-domains`。认证、工作空间隔离和 CSRF 要求以当前服务端实现为准；本次文档整理不修改接口。

## 配置与状态反馈

已入网的 Agent 离线时仍可创建或修改服务配置，连接恢复后下发；“配置已保存”不代表服务已开始运行。“运行中”表示 Agent 已连接、本地目标连接检查通过且服务入口已建立，公网访问仍需实际测试。服务列表支持协议、状态及 Agent 组合筛选，HTTP/HTTPS 地址可直接打开，复制使用旁边的独立按钮。

添加域名后进入该域名的详情与归属验证。证书方式和 DNS 高级参数分别保存；解析器留空使用 Caddy 默认，已有自定义地址保留；“验证并启用”会核对 Token 权限、保存凭据并切换证书方式，不会自动创建公网访问记录。刷新失败保留上次数据及其读取时间。服务详情可直达关联域名，返回时保留原服务上下文。

登录会话显示浏览器、系统和创建时间；无法识别的浏览器标签显示未知设备。设备标签来自浏览器自报信息，仅帮助识别，不作为认证依据。管理员代管其他空间时，资源弹窗显示目标空间；“我的账号”及登录会话始终作用于当前登录本人。

## 空间接入密钥

添加窗口会自动准备当前空间的长期密钥，可随时重新打开复制；密钥不自动过期。高级区域可重置密钥，旧密钥立即不能新增设备，已接入 Agent 和服务不受影响。删除一台 Agent 只撤销该设备身份，不影响其他设备或空间密钥；持有有效密钥的人仍可使用新数据目录添加新设备。不要分享部署配置，不要将包含私钥的数据目录复制给多个同时运行的实例。

Server 使用 ChaCha20-Poly1305 加密保存可再次读取的接入密钥。备份必须同时包含 nexo.db 和数据目录内 secrets/agent-access.key，后者丢失后不会自动重建以免覆盖解密材料。设备自身的 identity.json 需随 Agent 数据目录备份。新设备仅使用共享接入密钥，一次性设备凭证仅用于身份恢复。
